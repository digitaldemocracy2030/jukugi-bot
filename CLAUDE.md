# CLAUDE.md

## Project Overview

Breakout Deliberation OS (OSODP) — an open-source platform for small-scale deliberative discussions. Monorepo with a React frontend (React 19 + React Router 7 SPA + Vite + Tailwind CSS v4 + TanStack Query + shadcn/ui + LiveKit Components) and Hono backend deployed to Cloudflare Workers + D1 + R2.

## Commands

**Always use Docker for local development:**

```bash
docker-compose up                        # Start all services (preferred)
```

Direct pnpm commands (use only when debugging outside Docker):

```bash
pnpm install                             # Install dependencies
pnpm dev                                 # Run both frontend (5173) and backend (8787)
pnpm build                               # Build both apps
pnpm typecheck                           # TypeScript type checking
pnpm biome:check                         # Lint and format check (Biome)
pnpm biome:format                        # Auto-format with Biome
pnpm --filter backend test               # Run backend tests (Vitest)
pnpm --filter backend db:generate        # Generate Drizzle migrations (never write migration SQL by hand)
pnpm --filter backend db:migrate:local   # Apply migrations locally (D1)
pnpm --filter backend db:migrate:remote  # Apply migrations to remote D1
pnpm --filter backend cf-typegen         # Regenerate Cloudflare Workers types
pnpm --filter frontend generate:api      # Regenerate TypeScript API client from OpenAPI schema (Orval) — run after any backend change
```

## Repo-Specific Conventions (not inferable from code)

- **Biome**: tab indentation, double quotes, 100-char line width
- **Never hand-write migration SQL** — always generate from schema changes via `db:generate` with drizzle
- **All backend routes must use `@hono/zod-openapi`** — plain Hono routes break the OpenAPI schema and the Orval client
- **Frontend API client is auto-generated by Orval** (`src/api/gen/`) — run `generate:api` after any backend change. Never edit files under `src/api/gen/`
- **Frontend UI must go through the Design System (`app/components/design-system/`)** — do not use `components/ui/` (shadcn/ui) directly. See `app/components/design-system/GUIDE.md`
- **D1 data is not accessible from the Docker host** — `.wrangler` is a Docker volume. Debug via the API or `docker exec my-app-backend`
- **Never store sensitive data in LiveKit room metadata** — it is visible to all connected participants
- **Timestamps are stored as milliseconds** (cross-platform compatible)
- **Issues must use the template at `.github/ISSUE_TEMPLATE/issue.yml`**
