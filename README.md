# Breakout Deliberation OS (OSS)

## 概要

Breakout Deliberation OS は、小規模ブレークアウト型熟議を支援するためのオープンソースプラットフォームです。

参加者は配布された単一URLにアクセスするだけで、動画視聴、発言、割り込み、投票、アンケート回答、リアルタイム文字起こしの閲覧まで、すべてを一つの画面内で完結できます。ページ遷移はありません。

本プロジェクトは、自治体や市民団体、研究機関が安心して利用できる公共熟議インフラを目指しています。

---

## 目的

- 秩序ある小規模熟議を支える
- 民主的な進行決定を可能にする
- 参加者の納得感を高める
- 熟議の記録と検証を可能にする
- プライバシーを最優先に設計する

---

## 主な特徴

### 1. 単一URL・単一画面体験
参加者はリンクにアクセスするだけで参加できます。  
発言、投票、アンケート、アジェンダ確認、文字起こし閲覧まで、すべてが同一画面内で進行します。

### 2. 柔軟なフェーズ設計
管理者は、動画視聴、議論、投票、アンケートなどのフェーズを自由に構成できます。  
進行順序は固定ではありません。

### 3. 発言キューと割り込み
- 発言はキューで管理されます。
- 他者発言中でも短時間の割り込みが可能です。
- 割り込みは時間制限付きで、自動的に終了します。

### 4. 民主的な投票機能
投票によって以下を決定できます：

- 次のアジェンダに進むかどうか
- 発言時間の延長
- 不適切発言の扱い
- 合意の確認

強制ではなく、参加者による意思決定を原則とします。

### 5. リアルタイム文字起こし
議論はリアルタイムで文字起こしされ、参加者全員が閲覧できます。  
記録は後から検証可能です。

### 6. アーカイブと研究利用
- 音声はアーカイブとして保存可能
- 発言ログ、投票履歴などをエクスポート可能
- 熟議の質や意見変化の分析に利用可能

---

## プライバシー方針

- 個人情報と発言データは分離して保存されます。
- 匿名化を前提とした設計です。
- 外部AI利用時も、学習用途には使用されません。
- データ削除およびエクスポートが可能です。

本プロジェクトは、公共利用を前提に設計されています。

---

## 想定利用シーン

- 自治体による市民討議
- 市民団体のテーマ別熟議
- 学術研究における熟議実験
- 教育現場での対話型授業

## プロジェクトの位置づけ

本プロジェクトは単なる会議ツールではありません。  
熟議の秩序、民主的統治、記録可能性、公共性を同時に実装する「熟議基盤」です。
